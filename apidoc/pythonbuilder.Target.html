Creates a new Target.

An "input target", for example a source code directory, may may be created with just an item, as it has no dependencies, the state generator is derived automatically, because it is an existing directory, and nothing needs to be done, so it has no command.

Parameters
item:Trepresents the target, like a file or directory name
*dependenciesthe dependencies of this target
state:(str|Callable[[Target[T]], str])|Nonedescribes how to generate a state (checksum, fingerprint) for this target. The function must generate a small fingerprint for the Target. If not provided, the item must denote an existing file or directory. If given as a string, it must be "dir", "file", "new" or "fixed" for stateDirContent, stateFileContent, stateNew or stateFixed respectively.
name:strA nice name for the target to use, for example, on the command line. The default is str(item), so if it is like ``Path("build", "stuff", "woo.html") then the name could be just "woo", for example.
cmd:Callable[[Target[T]], None]|NoneDefines which command to run to (re-)create the target.
