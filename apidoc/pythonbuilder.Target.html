Creates a new Target.

An "input target", for example a source code directory, may may be created with just a name, as it has no dependencies, the state generator is derived automatically, because it is an existing directory, and nothing needs to be done, so it has no command.

Parameters
name:strrepresents the target, like a file or directory name
*dependenciesthe dependencies of this target
state:(str|Callable[[Target], str])|Nonedescribes how to generate a state (checksum, fingerprint) for this target. The function must generate a small fingerprint for the Target. If not provided, the name must denote an existing file or directory. If given as a string, it must be "dir", "file", "new" or "fixed" for stateDirContent, stateFileContent, stateNew or stateFixed respectively.
alias:strAn alterantive name for the target which is easier to use, say, on the command line. If the target name is like "build/stuff/bla.html" then the alias could be just "bla", for example.
cmd:Callable[[Target], None]|NoneDefines which command to run to (re-)create the target.
